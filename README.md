# Birthday Web Application [WIP]

A lightweight, responsive static web application designed to host customized birthday celebrations. Developed for deployment on GitHub Pages.

## Overview

This repository contains the source code for a frontend birthday celebration interface featuring custom styling, interactive scripts, and asset management.

## Architecture & Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Responsive Design)
* **Logic:** Vanilla JavaScript (ES6+)
* **Hosting:** GitHub Pages

## Deployment

This application is deployed via GitHub Pages.
